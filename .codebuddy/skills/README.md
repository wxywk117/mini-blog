# 项目级技能（Skills）

本目录用于存放本仓库的项目级技能，随代码一起纳入版本管理。

## 目录约定

```
.codebuddy/skills/
└── <技能名>/
    ├── SKILL.md      # 必需：技能说明与执行指引
    └── ...           # 可选：脚本、模板、参考文档
```

- 一个技能一个独立子目录，目录名即技能标识（小写短横线命名，如 `commit-style`）。
- `SKILL.md` 需在开头写清技能名称、触发场景与具体操作步骤，便于自动加载与人工查阅。
- 技能内引用的脚本或模板放在同目录下，使用相对路径引用，避免依赖仓库外的资源。

## 当前状态

目录暂时为空，仅有本说明文件占位（Git 不跟踪空目录）。后续新增技能时按上述约定组织即可。

## 版本管理说明

本仓库在 `.gitignore` 中对 `.codebuddy/` 采用白名单策略：仅跟踪 `skills/` 与 `plans/` 两个子目录，其余本地状态（缓存、会话、临时文件等）一律忽略，避免误提交。
